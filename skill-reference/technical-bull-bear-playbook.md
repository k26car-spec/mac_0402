# 台股 K 線：多空雙向判讀與技術名詞規則

## 原則
- 技術名詞非客觀唯一標準。先宣告使用週期（日K/週K）、資料來源、還原方式、OHLCV、日期、成交量口徑、均線計法與參數；所有顯示值按當次重查逐日OHLCV計算。
- 台股紅漲綠跌。紅K通常收盤高於開盤，黑/綠K通常收盤低於開盤；連續黑K與連續收跌是兩種定義，逐一驗證。不能從圖的顏色臆測漲跌。
- MA5/MA10/MA20(約月線)/MA60(約季線)/MA120(半年線)/MA240(年線)為約定慣例；視來源可有差異，使用最近N個交易日收盤算簡單均線。盤中穿越 vs 收盤穿越 vs 連續站穩要分開；均線值與走向必須計算，不可憑圖片估計。
- 前高前低/平台/箱體區間：依事件發生之前可見的擺動高低、例如左右各2~3根K棒確認，記錄確認延遲；不得事後把未來才確立的轉折點回填成當時已知。阻力支撐為區帶，不是保證有效的精確點位。
- 任何型態的成立、候選、驗證、失效要分清。即便量價符合也不等於後續必漲或必跌。

## 多頭由弱轉強、延續與衰竭
| 名稱 | 候選/成立判準 | 後續確認與失效 |
|---|---|---|
| 止跌候選 / 長下影線 | 低檔長下影，收盤位置相對日內區間偏高；成交值與5/20日均值比較 | 1~3日不再破低且廣度改善支持；再破低撤銷候選 |
| 大量換手 / 變盤K | 成交量或成交值高於20日均值（倍數標註），長實體或長影線 | 不預設向上；後續收盤突破高點/跌破低點判定方向，市場廣度、法人是否共振 |
| 收復5/10日線 | 收盤 > 相應當日MA；需有前日收盤 <= MA才稱「重新站回」 | 分辨盤中刺穿、收盤站穩；下一次回測不破且MA斜率改善為較強證據 |
| 黃金交叉 | 短均線自下穿越長均線，當日及前日兩組MA數值俱核 | 滯後指標；若仍在下降中的季線下不可單憑交叉稱全面多頭 |
| 量增價漲 / 帶量突破 | 收盤突破事前既定前高、箱體上緣或重要MA，量/成交值相對5/20日均量上升，量比及收盤位置註明 | 次日與3/5日不跌回突破區間，廣度與外資現貨擴散；放量長上影為失敗風險 |
| 突破後回測守穩 | 突破後回檔觸及前壓力區，收盤仍守住或迅速收復 | 可列「支撐轉換候選」，至少觀察續漲及量縮回檔；收盤連續跌回原箱體則失效 |
| 低點墊高 / 高點墊高 | 至少兩個事先定義的相鄰波段低點、高點逐步提高 | 必須標明轉折點日期及確認日，不用未來資料假裝當日已可得知 |
| 多頭排列 | MA5>MA10>MA20>MA60並觀察斜率與價格相對位置 | 趨勢延續的滯後證據，價格嚴重乖離時提示追高風險 |
| 均線糾結後向上發散 | 先計算均線距離縮小、後短中期MA同向上彎且價格突破盤整 | 需要量能與廣度支持；突破後失守可能是假突破 |
| 回檔量縮 / 上攻量增 | 上漲波段量能擴大，正常回檔量能低於上攻時及平均量 | 不是硬規則，需看成交值、波動率、外資交易與下跌家數 |
| 旗形/箱體整理後突破 | 事先定義盤整區間，上緣突破並收穩 | 需確認箱體形成前已有上升趨勢；跌回區內判定失敗 |
| W底 / 雙底 | 兩次低點接近、第二低點未明顯失守（定容差），且突破兩底間頸線 | 未突破頸線只稱候選，不憑兩根反彈認定完成 |
| 頭肩底 / 圓弧底 | 依定義可見完整型態及頸線，成交價量支援 | 頸線未突破前只列候選；避免事後擬合 |
| 強勢整理與領漲擴散 | 指數橫盤而相對強勢股、產業族群上漲家數與成交占比增加 | 核對ETF/半導體/AI/記憶體/金融，不只台積電單股撐盤 |
| 過熱與多頭衰竭 | 與MA20/60乖離擴大、長上影/爆量滯漲、創高而廣度/動能不再創高 | 只稱風險觀察；確認跌破關鍵支撐且資金惡化再升級 |

## 空頭、反彈與失效
| 名稱 | 候選/成立判準 | 後續確認與失效 |
|---|---|---|
| 跌破5/10/月/季線 | 收盤由上轉下穿越當日MA，計算MA斜率 | 單日失守只為警訊；3/5日無法收回與資金惡化加重證據 |
| 假突破 / 反彈受阻 | 盤中突破但收盤落回均線/前高下方；長上影、量價背離 | 需看下個交易日與3/5日，不能單根斷定轉空 |
| 跌破前低 / 箱體下緣 | 收盤低於事前可辨識支撐，列價位與日期 | 下破後反抽無法收復、放量且廣度惡化支持；快速站回為假跌破候選 |
| 連5根黑K | 連續5日收盤<開盤 | 與「連5日收跌」分開，不因連黑必推斷出清 |
| 死亡交叉 / 空頭排列 | 短均線向下穿越長線 / MA5<MA10<MA20<MA60 | 滯後風險證據，仍需外資/匯率/市場廣度確認 |
| 月線/季線反彈壓力 | 反彈接近下彎MA20/60，盤中觸及但收盤未站穩 | 連續多次受阻增強判斷；有效站回與回測守穩可撤銷 |
| M頭 / 頭肩頂 | 形成完整雙峰/頭肩及確認頸線收盤失守 | 僅圖形相似不稱完成；與成交量、市場廣度互驗 |
| 跳空缺口 | 當日高低區間與前日完全不重疊；區分上/下跳空 | 一般缺口/突破缺口/衰竭缺口屬解釋而非客觀已確認事實 |

## 技術判斷與八大核心資金訊號
1. 收盤價、當日OHLCV、成交值（TWSE一般股票/全證券區分）、5/20日均量及相對比重、價量背離。
2. 外資現貨：當日與近3/5日累計及成交額占比，區分連續買超與單日技術性回補、個股/族群買超擴散。
3. 台指期外資未平倉：多、空、淨口數與近3/5日變化，不能把淨空等同一定看空。
4. CBC USD/TWD收盤、近3/5日變化，USD/TWD升=台幣貶；搭配DXY/10年美債殖利率。
5. 費半SOX最近美股交易日及近3/5日、台積電ADR、韓股/KRW及半導體相對強弱。
6. TWSE+TPEx融資金額、近1/2/5日增減、追繳處分及維持率不同口徑；去槓桿不是必然賣壓已盡。
7. 市場廣度/櫃買/權值與AI、PCB、記憶體族群，檢查指數被少數權值股撐起。
8. 基本面與政策消息，區分財報結果、CapEx與訂單事實、傳聞與估值情緒。

## 雙向預警與呈現
- 同時標示「下跌風險等級：正常/觀察/警戒/高風險」與「轉多階段：未出現/止跌候選/初步轉強/回測確認/趨勢確認」。兩軸不同，不強迫單一分數判斷。
- 報告順序：先列日期與最新收盤/盤中、技術名詞及其數值判準；再列量價與外資等交叉證據；最後分開列「客觀已成立」「合理判讀」「失效條件」「下一交易日驗證」。若欠缺歷史完整K線，禁止聲稱均線交叉、KD/MACD數值已計算。
- 技術訊號可以先行提醒，不代表持續趨勢已確認；區分預警時點與型態後驗成立日，避免窺視未來。
- 用實際日期規則回測，報告最大回撤、錯誤警報、錯過的行情，記錄價格/訊號出現的當日資料可用性；不許用已知結局重寫當時的警告。
- 不把技術型態/百分比視為投資保證或個人化交易指令。
