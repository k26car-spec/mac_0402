# 黑K與回檔判斷模組（進階模組，搭配 technical-bull-bear-playbook.md 使用）

## 鐵律
- 不可看到三根黑K就判斷趨勢結束。
- 不可因量縮就判斷安全。

## 檢查順序
黑K位置 → 每根成交量 → 有沒有跌破重要支撐 → 均線方向 → 止跌/收復訊號 → 高檔過熱還是低檔起漲

## 連續黑K六分類
1. 上漲後正常休息
2. 短線獲利賣壓
3. 回測重要支撐
4. 高檔有人大量賣出
5. 中期趨勢開始轉弱
6. 尚未確認

## 三根黑K必答八題
1. 跌幅%
2. 量增減
3. 破支撐否
4. 距20日線
5. 60日線方向
6. 漲多拉回 vs 盤頭下殺
7. 下方支撐
8. 止跌條件

## 黑K的量怎麼讀
- 跌量縮
- 跌量增
- 量很小但跌很多（⚠️不等於安全）

## 止跌確認（至少湊兩項）
- 長下影線
- 收復實體一半
- 隔天過前高
- 量溫和增
- 站回5或10日線
- 支撐連兩天不破
- 同族群同步止跌
- 大盤回支撐

## 反彈強弱三分
止跌、反彈、轉強是三件不同的事（較強反彈 vs 較弱反彈的特徵要分開判讀，不可混用）

## 缺口與長紅K回測三等級
1. 強勢整理
2. 普通整理
3. 突破失敗

## 均線不能只看排列
排列偏多 ≠ 強，要看方向、距離、彎頭、站回速度。

## 高低點結構
- 上升結構
- 整理結構
- 轉弱結構

## 大盤與個股同步比較
抗跌 / 不漲 / 同步跌 / 大跌小跌組合判讀

## 國際指標連動（記憶體/半導體/AI必查）
美光、費半、DRAM/NAND報價、三星、海力士、美國科技股

## 投資結果四種
買後立刻漲／先整理再漲／判斷錯小幅停損／不交易也是一種結果

## 黑K健康檢查表輸出格式
連續黑K數量 / 累計跌幅 / 量變化 / 破5-10-20日線否 / 破前低否 / 第一支撐 / 止跌訊號
＋ 七選一性質判斷（上述六分類+尚未確認）
＋ 後續確認條件
